# AI RiskLens｜貿易融資單據智慧審核助手

104 × TiBaMe AI 產品經理課堂期末 Prototype。由單一 `index.html` 組成，可直接透過 GitHub Pages 發布，不需要安裝 Codex、Node、Python、資料庫或 API Key。

## 操作方法
1. 開啟 `index.html`，或進入 GitHub Pages Demo。
2. 左側選擇七個合成測試情境之一。
3. 點擊「開始檢核」，查看 R01–R04 規則引擎運算結果與模擬來源。
4. 每項可點選「確認異常」「排除異常」「待查證」，並輸入覆核註記。
5. 點「下載本次覆核紀錄」取得 JSON；或切換案件進行下一輪測試。

## 技術範圍
- **真實執行**：結構化資料正規化、規則式跨單據比對、差異提示、人工覆核與 JSON 結果匯出。
- **模擬部分**：OCR、AI 欄位擷取、原始文件定位與三份文件內容。**本專案沒有真實 OCR、LLM、資料庫或銀行系統串接。**
- 檢核規則：R01 貨品描述、R02 同品項數量、R03 包裝件數、R04 毛重（KG/LB）。
- 如資料缺失、包裝層級不同、語意無法確認、來源無法定位，顯示「無法判定」，不假設一致。

## 測試情境
| 情境 | 預期重點 |
|---|---|
| A 一致 | R01–R04 一致／無明顯衝突 |
| B 數量差異 | R02 疑似衝突：500 PCS vs 480 PCS |
| C 重量換算 | R04 1000 KG vs 2204.62262 LB 換算後一致 |
| D 包裝層級不同 | R03 無法判定 |
| E 描述可能等義 | R01 無法判定 |
| F 欄位缺漏 | R02 無法判定 |
| G 來源定位缺失 | R04 無法判定 |

完整審查時間減少至少 20%，且試測階段最終審查重大漏報 0 件。此 Prototype 只驗證部分規則與覆核流程，**無法據此宣稱達成完整審單效益**。

## GitHub Pages 發布
Repository → Settings → Pages → Build and deployment：Source = Deploy from a branch，Branch = `main`、Folder = `/(root)` → Save。
頁面網址格式：`https://你的帳號.github.io/AI-RiskLens/`。

## 資料保護
所有文件資訊均為虛構合成資料，不使用真實銀行交易資料或客戶資訊。
